# Sentiment Analysis Platform — Frontend

The frontend is built with React and Vite.

For architecture, prerequisites, environment configuration, API details, and setup instructions, see the [root project README](../README.md).

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Set `VITE_API_URL` in `frontend/.env.local` to the base URL of the FastAPI backend.
